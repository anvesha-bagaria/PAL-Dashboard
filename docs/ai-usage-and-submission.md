# AI use and submission notes

## AI use

AI assistance was used to inspect the planning pack, implement static UI and pure aggregation code, create tests and documentation, and review KPI/UI behavior. The dataset remains the provided synthetic dataset generated by `tools/generate_data.py`; no real learner or school records were added.
